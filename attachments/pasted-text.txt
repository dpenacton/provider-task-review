go thru thsi # Handoff — Provider "Orders" Section Redesign (Minimal Care Portal)



Prepared 2026-08-21 for the UX/design agent. Everything in this folder is self-contained;

sources are cited so any claim can be re-verified.



## What this is



An evidence-backed, fully interactive prototype of a **new doctor-facing Orders section**

for the Minimal EHR care portal, replacing the current 7-tab task drawer for

`OrderEvaluation` tasks with a LifeRx/TelyRx-style model: one Orders list, **one page per

order**, everything needed to decide visible upfront, approval in one click.



- **Live artifact (interactive, share from its menu):** https://claude.ai/code/artifact/09a121da-9f00-4837-8e5d-d4b2c949ce56

- **Local prototype file:** `orders-redesign.html` (this folder). Single self-contained HTML —

open in a browser. All state in JS; localStorage persistence; "Reset demo data" in the

Demo controls (bottom-left).

- **Built-in guided tour:** "▶ Start walkthrough" (guide bar or Demo controls) — 15 spotlight

steps, each with "What we did / Why". The step definitions live in the `TOUR` array inside

the HTML — they are the canonical rationale, keep them in sync with any design change.

- **Evidence screenshots:** `evidence/` (see inventory at the bottom).



## The problem (and the real insight)



Dr. Miller (external prescriber, US) reviews RX storefront orders. Management asked for

"minimal clicks for approvals, details upfront."



**The approve button was never the problem.** In the current dev portal, "Approve order

line" is already ONE click with no confirmation (verified live on dev-care, task TASK6301,

2026-08-21). The real costs are:



1. **Context assembly** — 7 drawer tabs (Overview / Order Evaluation / Visit Note /

Past Tasks / History / Files / Messages); shipping address shown nowhere; patient's

other orders shown nowhere; legacy noise ("Primary Disability Information", Driver's

License / Parking Permit fields).

2. **No per-order URL** — the drawer lives inside the queue page, so the doctor's actual

habit (Ctrl-click ~10 cases into 10 browser tabs, approve, close, next) is impossible;

"back नहीं आता".

3. **Medication swap dropdown exposes the entire catalog** (~50 items incl. $0.00 peptides)

as one flat list.

4. **Auto-refill is unlimited today** — the order-refill cron clones the prescription with

`taskId: null`, no task, no review, forever until cancelled. There is NO refill-count

column anywhere in the schema. (This turns the meeting's "approve with 3 refills" into a

new *safety control*, not a convenience.)

## Implementation seams (from the code trace of `minimal-care-portal`, branch dev)



The backend already supports most of this — the page is mostly assembling data the server

returns. Key facts for feasibility conversations:



- **Approval is per LINE, not per order.** Each `order_items` row has a 1:1 `taskId`

(schema.ts:2813). An "Approve whole order" button loops the per-line server action.

- Server actions `approveOrderEvaluation` / `declineOrderEvaluation` are taskId-keyed

(`src/lib/orders/order-evaluation-actions.ts:308, :477`) and reusable from a new page.

Note: `revalidatePath` hardcodes `/new-tasks` (:461, :573) and there is **no server-side

provider-authorization check** — flag to engineering.

- Shipping address: `orders.shippingAddress` jsonb snapshot (schema.ts:2778), already

returned by `getOrderLineForTask` (:643-655); only admin renders it (OrderOpsDetail.tsx:289-295).

- Order header status is derived from lines: `placed | in_review | approved |

partially_approved | declined` (schema.ts:2773; recomputeOrderStatus :65-90).

- Refill plumbing: `patient_subscriptions` (schema.ts:2834-2853) is an open-ended cadence

loop (`nextRefillAt`); refill cron `src/lib/orders/refill-processor.ts` clones the Rx with

`taskId:null` (:133-150) — zero review. **"Approve with N refills" needs:** a

`refillsRemaining` column, a count input in the approve action payload, the seam at

`maybeCreateSubscription` (order-evaluation-actions.ts:214-294), and a decrement +

cancel-at-zero in `processOneSubscription` (:172-183).

- Price difference = `(defaultPrice − pricePaid) × qty`, auto charge/refund of the delta on

the saved card (`chargeOrRefundDelta`, order-evaluation-actions.ts:92-200).

- Provider routes live under `src/app/(main)/provider/[providerId]/*`; sidebar nav array in

`src/app/(main)/_components/provider/SideBar.tsx:38-86`. **No provider orders page exists**

— the "new order section" in the repo is admin-only Order Ops (`admin/orders`, read-only

clinical).

- TelyRx is already the team's internal benchmark: the medication catalog CSV carries

"VITAstir / TelyRx / LIMITLESS" competitor price columns

(`docs/import-minimal-medication-catalog.md:17`). No e-prescribing vendor integration

exists — fulfilment is in-house, so refill-cap logic lives entirely in our cron.

## Open decisions for you to weigh in on



1. Refill options set (None/1/2/3/5) and default 3 — Miller asked for 3; Dishant floated

auto-approve-all. Product owner question, pending Mike/Miller.

2. Whether swap should exist at all for providers, vs admin-only.

3. Approve-hold duration (5 s) and whether Undo should also exist post-transmission

(a "reclaim" — the current portal has Unmark Review).

4. Batch behaviours: we deliberately did NOT add multi-select batch approve (no market

precedent, liability); auto-advance covers the speed need. Challenge if you disagree.

5. Empty/edge states beyond what's built (licence mismatch hard-stop screen is described

but only the badge is rendered).

6. Known cosmetic caveat: the walkthrough's dim veil uses a canvas overlay (driver.js-style)

+ repaint heartbeat; on one test machine's *headless screenshots* the translucent layer

didn't composite (ring + card still fine). Verify in a real browser; tune in

`drawDim()` / `.tour-spot` if needed.

let filter = 'needs';
function setFilter(f){ filter = f; render(); }

function listView(){
  const groups = {
    needs: o => o.status==='pending' || o.status==='refill',
    approved: o => o.status==='approved',
    declined: o => o.status==='declined',
    all: () => true
  };
  const shown = orders.filter(groups[filter] || groups.all);
  const nNeeds = orders.filter(groups.needs).length;
  const nAppr = orders.filter(groups.approved).length;
  const nDecl = orders.filter(groups.declined).length;

  const rows = shown.map(o => {
    const l = o.lines[0];
    const acts = (o.status==='pending' || o.status==='refill') ? `
      <button class="btn primary sm" onclick="event.preventDefault(); location.hash='#order/${o.id}'">Open &amp; review</button>
      ${o.status==='refill' ? `<button class="btn outline-blue sm" onclick="event.preventDefault(); quickApprove('${o.id}')">Approve refill</button>`:''}

      : `<button class="btn outline sm" onclick="event.preventDefault(); location.hash='#order/${o.id}'">View</button>`;
    return `<a class="order-row" href="#order/${o.id}" title="Ctrl-click opens in a new tab">
      <div class="pt">
        <div class="avatar">${initials(o.patient.name)}</div>
        <div class="who">
          <div class="nm">${esc(o.patient.name)} ${o.patient.newPatient?'<span class="pill amber" style="margin-left:4px">New patient</span>':''}</div>

function orderView(id){
  const o = byId(id);
  const p = o.patient;
  const pend = pendings();
  const idx = pend.findIndex(x=>x.id===id);
  const decided = o.status==='approved' || o.status==='declined';

  const tabs = [
    {k:'order', label:'Order', n:o.lines.length},
    {k:'patient', label:'Patient', n:null},
    {k:'past', label:'Past Orders', n:o.pastOrders.length},
    {k:'docs', label:'Documents', n:o.docs.length},
    {k:'rx', label:'Prev Prescriptions', n:o.prevRx.length},
  ];

  return `
  <div class="backline">
    <a href="#orders">← All orders</a>
    <span class="spacer"></span>
    ${idx>=0?`<span class="pager"><span class="num">${idx+1} of ${pend.length} pending</span>
      <button onclick="stepOrder(-1)" aria-label="Previous order">‹</button>
      <button onclick="stepOrder(1)" aria-label="Next order">›</button></span>`:''}
  </div>

  <div class="card order-head ann">
    <div class="avatar">${initials(p.name)}</div>
    <div>
      <h2>${esc(p.name)}</h2>
      <div class="hmeta num">
        <span>${p.code}</span><span>DOB ${p.dob} · ${p.age} yrs · ${p.sex}</span>
        <span class="pill ${p.licensed?'green':'red'}">${p.licensed?'✓ Licensed in '+p.state:'✗ Not licensed in '+p.state}</span>
        ${p.newPatient?'<span class="pill amber">New patient</span>':''}
        ${o.status==='refill'?`<span class="pill amber">Refill ${o.refillInfo.n} of ${o.refillInfo.of}</span>`:''}
      </div>
    </div>
    <div class="right">
      <div class="amount num">${money(orderTotal(o))}<small>Paid · ${o.id} · ordered ${o.ordered}</small></div>
      ${statusPill(o)}
    </div>
    <button class="ann-dot" style="bottom:-10px; left:24px;" onclick="annToggle('a-head')">4</button>
    <div class="ann-card" id="a-head" style="bottom:-120px; left:24px;">
      <b>Decision context upfront</b>
      Identity, licence match, payment and new-vs-returning — visible before scrolling. No Overview tab hunt.
    </div>
  </div>

  <div class="tabs ann">
    ${tabs.map(t=>`<button class="tab ${currentTab===t.k?'on':''}" onclick="setTab('${t.k}')">${t.label}${t.n!==null?`<span class="tn num">${t.n}</span>`:''}</button>`).join('')}
    <button class="ann-dot" style="top:-10px; right:8px;" onclick="annToggle('a-tabs')">5</button>
    <div class="ann-card" id="a-tabs" style="top:18px; right:8px;">
      <b>7 tabs → 5, reordered</b>
      Order first (“order evaluation is the first tab”), then patient context. Visit Note auto-generates on approval; Messages dropped — “he doesn't look at it”.
    </div>
  </div>

  ${currentTab==='order' ? tabOrder(o) : ''}
  ${currentTab==='patient' ? tabPatient(o) : ''}
  ${currentTab==='past' ? tabPast(o) : ''}
  ${currentTab==='docs' ? tabDocs(o) : ''}
  ${currentTab==='rx' ? tabRx(o) : ''}

  ${!decided ? actionbar(o) : decidedBar(o)}
  `;
}

function tabOrder(o){
  const p = o.patient;
  const linesHtml = o.lines.map((l, i) => {
    const d = l.swaps[l.swapIdx]?.d || 0;
    return `<div class="line">
      <div class="top">
        <div>
          <div class="medname">${esc(l.med)}</div>
          <div class="medsub">${esc(l.sub)}</div>
        </div>
        <div class="lprice num"><b>${money(l.price + d)}</b><span>paid ${o.status==='refill'?'(refill — no charge to review)':''}</span></div>
      </div>
      <div class="sig"><b>DIRECTIONS (SIG)</b>${esc(l.sig)}</div>
      ${l.declined ? `<div class="declined-strip">Line declined — will be refunded ${money(l.price)} on sign-off. <a href="javascript:void(0)" onclick="toggleLine('${o.id}',${i})">Restore</a></div>` : `
      <div class="foot">
        <div class="refills ann" style="position:relative;">
          <label for="ref-${i}">Refills</label>
          ${l.titrates
            ? `<span class="pill amber">Dose titrates — re-evaluate each cycle</span><span class="refnote">no standing refills; next cycle returns here pre-filled at the next protocol dose</span>`
            : `<span class="seg" role="group" aria-label="Refill count">
                ${[0,1,2,3,5].map(n=>`<button class="${l.refills===n?'on':''}" onclick="setRefills('${o.id}',${i},${n})">${n===0?'None':n}</button>`).join('')}
              </span>
              <span class="refnote">${l.refills>0?`auto-ships each cycle — no task for you, stops after ${l.refills}`:`patient re-evaluated next cycle`}</span>`}
          <button class="ann-dot" style="top:-12px; left:44px;" onclick="annToggle('a-ref-${i}')">10</button>
          <div class="ann-card" id="a-ref-${i}" style="top:14px; left:44px;">
            <b>Refill cap — a new safety control</b>
            Today auto-refill is unlimited: the cron clones the prescription with no task and no review until someone cancels. This selector puts the count in the doctor's signature, TelyRx / LifeFile style.

        </div>
        ${o.lines.length>1?`<button class="btn outline sm" onclick="toggleLine('${o.id}',${i})">Decline this line</button>`:''}
      </div>`}
      ${l.swaps.length>1 ? (
        (l.swapOpen || l.swapIdx>0)
        ? `<div class="swapline">

            </span>
            ${l.swapIdx===0?`<a href="javascript:void(0)" style="font-size:12px" onclick="toggleSwap('${o.id}',${i})">Cancel</a>`:''}
          </div>`
        : `<div class="swapline"><a href="javascript:void(0)" style="font-size:12px" onclick="toggleSwap('${o.id}',${i})">Swap medication (${l.swaps.length-1} alternative${l.swaps.length>2?'s':''}) →</a></div>`
      ) : ''}
    </div>`;
  }).join('');

  return `<div class="cols ann">
    <div>
      <div class="card sec" id="sec-items">
        <h3>Items ordered <span class="rt num">${o.lines.length} line${o.lines.length>1?'s':''}</span></h3>
        ${linesHtml}
      </div>
      <button class="ann-dot" style="top:170px; left:-10px;" onclick="annToggle('a-price')">6</button>
      <div class="ann-card" id="a-price" style="top:196px; left:-10px;">
        <b>Price difference — only when it matters</b>
        The permanent “Price difference: no adjustment needed” block is gone. It appears only when a swap actually changes the price.
      </div>
    </div>
    <div class="snap">
      <div class="card sec">
        <h3>Patient snapshot <span class="rt"><a href="javascript:void(0)" onclick="setTab('patient')">Full profile →</a></span></h3>
        <dl class="kv">
          <dt>Height / Weight</dt><dd class="num">${p.height} · ${p.weight} (BMI ${p.bmi})</dd>
          <dt>Allergies</dt><dd>${esc(p.allergies)}</dd>
          <dt>Past orders</dt><dd class="num">${o.pastOrders.length} ${o.pastOrders.length?`· last ${o.pastOrders[0].date}`:''}</dd>
        </dl>
        <div class="addr ann"><small>SHIPS TO</small>${esc(p.address)}
          <button class="ann-dot" style="top:-10px; right:-10px;" onclick="annToggle('a-addr')">7</button>
          <div class="ann-card" id="a-addr" style="top:16px; right:-10px;">
            <b>Address, finally visible</b>

        <h3>Intake highlights <span class="rt"><a href="javascript:void(0)" onclick="openDoc('${o.id}',0)">Open intake PDF</a></span></h3>

  const o = JSON.parse(snap);
  const i = orders.findIndex(x=>x.id===o.id);
  if(i>=0) orders[i] = o;

function finishDecision(o, kind){
  undoSnapshot && clearTimeout(undoTimer);
  const snap = undoSnapshot; // previous pending undo is committed implicitly
  undoSnapshot = null;

  const before = snapshotFor(o.id);
  o.status = kind;
  o.decidedAt = 'Aug 21, 2026';
  if(kind==='declined' && !o.declineReason) o.declineReason = 'patient refunded in full.';
  store.save();

  const next = pendings()[0];
  const med = o.lines[0].med.split(' (')[0];
  const msg = kind==='approved'
    ? `<b>Approved &amp; signed</b> — ${esc(med)} for ${esc(o.patient.name)}${o.lines[0].refills?` · ${o.lines[0].refills} refills`:''}`
    : `<b>Declined</b> — ${esc(o.patient.name)} refunded ${money(orderTotal(o))}`;

  toastUndo(msg, before, () => {
    if(next){ location.hash = '#order/' + next.id; }
    else { location.hash = '#orders'; }
  });

  if(next){ location.hash = '#order/' + next.id; currentTab='order'; }
  else { location.hash = '#orders'; }
  render();
}

function approve(id){ const o = byId(id); if(o.status!=='pending' && o.status!=='refill') return; declineOpen=false; finishDecision(o, 'approved'); }
function decline(id){
  const o = byId(id); if(o.status!=='pending' && o.status!=='refill') return;
  const sel = document.getElementById('decline-reason');
  o.declineReason = (sel ? sel.value : 'declined by provider') + ' — patient refunded in full.';
  declineOpen=false; finishDecision(o, 'declined');
}
function quickApprove(id){
  const o = byId(id);
  if(o.patient.newPatient){ location.hash = '#order/'+id; toast('New patient — review the full order first.'); return; }
  finishDecision(o, 'approved');
}
function reopen(id){
  const o = byId(id);
  o.status = (o.refillInfo ? 'refill' : 'pending');
  delete o.decidedAt;
  store.save(); render();
  toast('Order reopened for review.');
}

function stepOrder(dir){
  const pend = pendings();
  if(!pend.length) return;
  const r = route();
  let i = pend.findIndex(x=>x.id===r.id);
  if(i<0) i = 0; else i = (i + dir + pend.length) % pend.length;
  location.hash = '#order/' + pend[i].id;
}

/* ---------- toasts ---------- */
function toast(html, ms=3200){
  const w = $('#toasts');
  const el = document.createElement('div');
  el.className = 'toast';
  el.innerHTML = `<span>${html}</span>`;
  w.appendChild(el);
  setTimeout(()=> el.remove(), ms);
}
function toastUndo(html, beforeSnap, onCommit){
  const w = $('#toasts');
  const el = document.createElement('div');
  el.className = 'toast';
  let secs = 5;
  el.innerHTML = `<span>${html}</span><button id="undo-btn">Undo · <span class="num">${secs}</span>s</button>`;
  w.appendChild(el);
  const btn = el.querySelector('#undo-btn');
  const iv = setInterval(()=>{
    secs--;
    if(secs<=0){ cleanup(); return; }
    const n = btn.querySelector('.num'); if(n) n.textContent = secs;
  }, 1000);
  function cleanup(){ clearInterval(iv); el.remove(); }
  btn.addEventListener('click', ()=>{
    restoreSnapshot(beforeSnap);
    store.save();
    cleanup();
    const o = JSON.parse(beforeSnap);
    location.hash = '#order/' + o.id;
    render();
    toast('Undone — order is back in review.');
  });
  setTimeout(cleanup, 5200);
}

let tourHeart = null;
function startTour(){
  store.reset(); filter='needs'; annOn=false; guideOn=false; demoOpen=false; declineOpen=false;
  if(location.hash !== '#orders') location.hash = '#orders';
  // Heartbeat: some compositors skip freshly-inserted translucent layers until the
  // layer's style changes in a later frame — an imperceptible opacity toggle fixes that.
  if(!tourHeart) tourHeart = setInterval(() => {
    const c = document.getElementById('tour-dimc');
    if(c) c.style.opacity = (c.style.opacity === '0.999' ? '1' : '0.999');
  }, 300);
  tourGo(0);
}
function endTour(){
  tourIdx = -1;
  if(tourHeart){ clearInterval(tourHeart); tourHeart = null; }
  document.getElementById('tour-root').innerHTML = '';
  guideOn = true; store.save(); render();
  toast('Walkthrough ended — explore freely, or restart it from Demo controls.');
}
function tourGo(i){
  if(i < 0) i = 0;
  if(i >= TOUR.length){ endTour(); return; }
  tourIdx = i;
  const s = TOUR[i];
  if(s.pre) s.pre();
  render();
  requestAnimationFrame(()=>{
    const el = s.sel ? document.querySelector(s.sel) : null;
    if(el) el.scrollIntoView({ block:'center', behavior:'auto' });
    setTimeout(placeTour, 60);
  });
}

    <canvas id="tour-dimc"></canvas>

function drawDim(hole){
  const c = document.getElementById('tour-dimc');
  const dpr = window.devicePixelRatio || 1;
  const iw = window.innerWidth, ih = window.innerHeight;
  if(c.width !== Math.round(iw*dpr) || c.height !== Math.round(ih*dpr)){
    c.width = Math.round(iw*dpr); c.height = Math.round(ih*dpr);
    c.style.width = iw+'px'; c.style.height = ih+'px';
  }
  const ctx = c.getContext('2d');
  ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
  ctx.clearRect(0, 0, iw, ih);
  ctx.fillStyle = 'rgba(9, 9, 11, 0.45)';
  ctx.fillRect(0, 0, iw, ih);
  if(hole){
    ctx.save();
    ctx.globalCompositeOperation = 'destination-out';
    ctx.beginPath();
    const rr = 12, {x, y, w, h} = hole;
    ctx.moveTo(x+rr, y);
    ctx.arcTo(x+w, y, x+w, y+h, rr); ctx.arcTo(x+w, y+h, x, y+h, rr);
    ctx.arcTo(x, y+h, x, y, rr); ctx.arcTo(x, y, x+w, y, rr);
    ctx.closePath();
    ctx.fill();
    ctx.restore();
  }
}
function placeTour(){
  const root = document.getElementById('tour-root');
  if(tourIdx < 0){ root.innerHTML=''; return; }
  ensureTourEls();
  const s = TOUR[tourIdx];
  const el = s.sel ? document.querySelector(s.sel) : null;
  const iw = window.innerWidth, ih = window.innerHeight;
  const card = document.getElementById('tour-card');
  const spot = document.getElementById('tour-spot');

  card.innerHTML = `
    <div class="t-step num">Step ${tourIdx+1} of ${TOUR.length}</div>
    <h4>${s.title}</h4>
    <div class="t-body">
      <div><b>What we did</b>${s.what}</div>
      <div><b>Why</b>${s.why}</div>
    </div>
    <div class="t-foot">
      ${tourIdx>0?`<button class="btn outline sm" onclick="tourGo(${tourIdx-1})">← Back</button>`:''}
      <button class="btn blue sm" onclick="tourGo(${tourIdx+1})">${tourIdx===TOUR.length-1?'Finish':'Next →'}</button>
      <button class="t-end" onclick="endTour()">End tour</button>
    </div>`;

  if(el){
    const r = el.getBoundingClientRect();
    const pad = 7;
    const vT = r.top - pad, vL = r.left - pad, vW = r.width + pad*2, vH = r.height + pad*2;
    drawDim({ x: vL, y: vT, w: vW, h: vH });
    spot.style.display = 'block';
    spot.style.left = vL+'px'; spot.style.top = vT+'px'; spot.style.width = vW+'px'; spot.style.height = vH+'px';
    const ch = card.offsetHeight, cw = card.offsetWidth;
    let top = r.bottom + 16;
    if(top + ch > ih - 12) top = r.top - ch - 16;
    if(top < 12) top = Math.max(12, (ih - ch)/2);
    let left = Math.min(Math.max(12, r.left), iw - cw - 12);
    card.style.top = top + 'px'; card.style.left = left + 'px';
  } else {
    drawDim(null);
    spot.style.display = 'none';
    card.style.top = Math.max(12,(ih - card.offsetHeight)/2) + 'px';
    card.style.left = Math.max(12,(iw - card.offsetWidth)/2) + 'px';
  }
}

document.addEventListener('keydown', e => {
  if(e.target.matches('input, textarea, select')) return;
  if(tourIdx >= 0){
    if(e.key==='ArrowRight' || e.key==='Enter'){ e.preventDefault(); tourGo(tourIdx+1); }
    else if(e.key==='ArrowLeft'){ e.preventDefault(); tourGo(tourIdx-1); }
    else if(e.key==='Escape'){ endTour(); }
    return;
  }
  const r = route();
  if(r.view!=='order') return;
  const o = byId(r.id);
  const live = o.status==='pending'||o.status==='refill';
  if(e.key==='a'||e.key==='A'){
    if(!live) return;
    if(o.patient.newPatient){ toast('New patient — first prescription. Review, then use the Approve button.'); return; }
    approve(o.id);
  }
  if(e.key==='d'||e.key==='D'){
    if(!live) return;
    if(o.patient.newPatient && !declineOpen){ declineOpen = true; render(); return; }
    if(!declineOpen){ declineOpen = true; render(); }
  }
  if(e.key==='ArrowRight'){ stepOrder(1); }

});
